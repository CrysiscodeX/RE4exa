# RE4exa
Umbrella brand for a family of reverse-engineering and autonomous-analysis tools under the RE4exa ecosystem.

RE4exa is independent and is not affiliated with REA or the other projects studied here (see [NOTICE](research/rea-self-analysis/NOTICE.md)).

| Path | Contents |
|---|---|
| [`research/rea-self-analysis/`](research/rea-self-analysis) | REA run against its own published package: techniques, measured gaps, lens experiments with nine related repositories |
| [`research/dissection/`](research/dissection) | Ten repositories dissected into one knowledge graph; the merged product design and its first-principles evaluation |
| [`tools/rex/`](tools/rex) | The merged product: evidence-first investigation CLI + MCP server for agents |
| [`tools/dissect/`](tools/dissect) | Repositories as a queryable knowledge graph (CLI + MCP) |
| [`prototypes/rea-durable-evidence/`](prototypes/rea-durable-evidence) | REA tool calls as Absurd durable steps, so Evidence survives crashes |
| [`standard/`](standard) | RQS-2030, a quality standard for software that people and AI agents rely on, aimed at 2030-35: 62 criteria in 13 dimensions, red lines, gap and opportunity lenses, re-engineering actions ([read it](standard/RQS-2030.md)) |
| [`tools/rqs/`](tools/rqs) | Evidence-first reviews against RQS-2030: probes, suggested levels, scoring, reports, comparisons (CLI + MCP) |
| [`research/rqs-review/`](research/rqs-review) | RQS-2030 applied to the fourteen repositories and RE4exa: scores, 148 gaps, 85 opportunities, a foundation blueprint, reviewer agreement |
| [`skills/`](skills) | Agent skills for rex, dissect and rqs |

RE4exa has no LICENSE file yet, so others cannot legally reuse the code; its own RQS-2030 review
lists this as red line RL-1. Choosing a licence is the owner's decision.
