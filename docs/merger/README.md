# Merger brainstorm: leanrea, rea, pi durable and absurd

This is a layered and documented brainstorm. It asks whether combining four repositories would produce a better product and, if so, what that product would be.

The phase ends with 3 or 4 candidate concepts for the owner to choose from. It contains no code and no build plan.

Start with the [charter](00-charter.md): the question, the roles, the evidence and debate rules, and the guardrails. The [journal](journal.md) records the reasoning step by step.
