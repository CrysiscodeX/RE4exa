## identify

### `identify.file`

What a file is: format, format families and MIME type, from its first 256 KiB and its name.

Effect: read. Cost: cheap. Output from the target is not target text. Platforms: linux, darwin, win32.

| Argument | Type | Required | Default | Meaning |
|---|---|---|---|---|
| `path` | string (≤ 4096 chars) | yes |  | File path inside the workspace |

Example: A universal Mach-O.

```json
{"operation":"identify.file","path":"hello-universal-macos-s"}
```

Result includes:

```json
{"format":"macho-fat"}
```

Example: A PE DLL.

```json
{"operation":"identify.file","path":"lib-x86_64-windows-gnu-s.dll"}
```

Result includes:

```json
{"format":"pe"}
```

Ledger rows: `leanrea/LEAN-C04`.

## inventory

### `inventory.native`

One-call inventory of a native binary: per architecture slice, its kind, interpreter, own name (soname, DLL name or install name), linked libraries, exported and imported symbols, and language markers.

Effect: read. Cost: cheap. Output from the target is untrusted (sent inside the untrusted-content envelope). Platforms: linux, darwin, win32.

| Argument | Type | Required | Default | Meaning |
|---|---|---|---|---|
| `path` | string (≤ 4096 chars) | yes |  | File path inside the workspace |
| `limit` | integer (≥ 1, ≤ 5000) | no | `200` | Most export or import names listed per slice |

Example: The exports of a shared library.

```json
{"operation":"inventory.native","path":"lib-x86_64-linux-gnu.2.28-s.so"}
```

Result includes:

```json
{"format":"elf","slices":[{"exports":{"names":["reax_add","reax_apply","reax_counter","reax_mul","reax_version"]}}]}
```

Example: Both slices of a universal binary.

```json
{"operation":"inventory.native","path":"hello-universal-macos-s"}
```

Result includes:

```json
{"format":"macho-fat","slices":[{"arch":"x86_64"},{"arch":"aarch64"}]}
```

Ledger rows: `rea.tool/list_architectures`, `rea.tool/inspect_native_exports`, `rea.tool/inspect_pe_imports`, `leanrea/LEAN-T11`, `leanrea/LEAN-T15`.
