# @re4exa/core

The shared engine under [Assay](../../apps/assay) and reax (`apps/reax`, in progress). It has no
runtime dependencies beyond Node's built-ins (`node:sqlite` included).

| Module | What it is |
|---|---|
| `kernel/` | Durable SQLite kernel: tasks, attempts, leases with a write fence, checkpoints, intents before effects (`safe` / `keyed` / `unsafe` replay), receipts, topics, mailbox, budgets, a hash-chained case log |
| `evidence/` | Claim records (`re4exa.claim/2`, reads `assay.claim/1`) with ProbeKey / ObservationId / FindingKey, unknowns with revisions, claims, calibration |
| `probes/` | Model-free probe engine, built-in readers, the router pack (leanrea's router as data), reach table, finding diffs |
| `verifier/` | Re-runs `seen` claims against evidence (10 predicates) |
| `policy/` | Untrusted-content envelope and session taint, approval queue, secret redaction, child-process environment allow-list |
| `mcp/` | Result handles, workspace path guard, path suggestions |
| `errors.ts` | Stable failure codes; apps extend them with `defineFailureModes` |
| `testing/` | Fixture generators, the benchmark corpus and test helpers (not built into `dist/`) |

## Using it

Apps import subpaths without an extension: `import { Kernel } from "@re4exa/core/kernel/kernel"`.
The package exports TypeScript source under the `source` condition and built JavaScript by default:

- **From a source checkout,** run Node with `--conditions=source`. The repo's
  `scripts/with-source.mjs` sets it for tests and every process they start.
- **Installed packages** use `dist/`, which `npm run build` (and `npm pack`) produces.

Node 24.15 or later. Tests: `npm test`. Coverage gate: `npm run coverage`. Failure modes:
[docs/failure-modes.md](docs/failure-modes.md), generated by `npm run gen-docs`.
