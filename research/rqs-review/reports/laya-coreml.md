## Scope

Flags: `distributed`, `has_ui`, `heavy_compute`, `network_service`, `parses_untrusted`, `uses_llm`. Not set: `executes_code`, `uses_crypto`.

Profile ml-system: a Core ML conversion and inference runtime for laya checkpoints plus six published bundles. uses_llm=true (MCP server and agent-framework integrations executed by agents; no LLM is called); has_ui=true because the wheel ships the Rich terminal Snake demo (laya-coreml-snake); executes_code=false (only fixed helper commands such as sysctl and ffmpeg); network_service (laya-coreml-serve), parses_untrusted (HTTP bodies, downloaded .mlpackage graphs compiled by native Core ML), heavy_compute (conversion and on-device inference with measured energy) and distributed (PyPI, Hugging Face) are true; uses_crypto=false (SHA-256 integrity checks and a content-addressed cache only, no signing, encryption or key exchange). Static review at 7b36334 (shallow clone); Hugging Face bundles and cards were not reachable and no Apple hardware was available, so speed, energy and fidelity claims were checked against committed result files.

- Question: Does the port preserve upstream decisions, and is that checked independently of the port? Yes on fixtures: 189/189 selected answers on the general bundles, 59/59 fitting questions on ANE L96 with maximum drift 0.002925 (W8 0.014393) under a 0.02 gate, and CI checks host code and outputs against pinned upstream. Real-bundle checks run only on the maintainer's machine; fidelity is not task accuracy, as the README says.
- Question: Are the speed and energy claims reproducible and honestly scoped? Yes within limits: every headline figure matches committed results with environment, sample size, bootstrap intervals and net-negatives (10x target missed, ordinary export slower than MLX). One machine, not CI, not independently reproduced.
- Question: Can users verify what they install? Partially: pinned bundle revisions and checksums are documented and the cache is integrity-checked, but default loads are unpinned and unverified, and PyPI releases carry no attestations.
- Not examined: Hugging Face bundles and their published model cards (not reachable); no conversion, inference or energy run (no Apple hardware).; Git history (shallow clone): release cadence and contributor count.; experiments/ane_engineering scripts and the Rust pstr_sampler internals beyond their README and provenance fields.; Runtime behaviour of laya-coreml-serve, the MCP server and the Snake terminal UI (not run).; The laya-mlx sibling project (not in the reviewed set).; PyPI project settings, branch protection and whether GitHub private vulnerability reporting is enabled.
