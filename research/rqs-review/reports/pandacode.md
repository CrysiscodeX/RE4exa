## Scope

Flags: `distributed`, `executes_code`, `has_ui`, `network_service`, `parses_untrusted`, `uses_crypto`, `uses_llm`. Not set: `heavy_compute`.

agent-harness: a Tauri desktop app that launches coding-agent CLIs (Claude Code, Codex, Kimi, OpenCode, Antigravity, Grok, GLM/MiMo) as host processes and serves them app tools over a per-turn loopback MCP server. Flags: uses_llm, has_ui and executes_code as probed; network_service set because the probe missed Rust listeners (per-turn MCP server providers/mcp_host.rs:82, bots web chat on 127.0.0.1:47321 bots/channels/http.rs:208); parses_untrusted (web pages, GitHub issues, VSIX archives, chat and webhook messages, VNC frames); uses_crypto (minisign update verification, HMAC/SigV4, VNC DES); distributed (GitHub Releases with auto-update); heavy_compute off because inference runs in the vendors' services and local VMs are user workloads. Red-line decisions: the automatic SEC-6 suspicion (4 pattern hits) is rejected because all four sit in #[cfg(test)] modules or a test file with placeholder values; SEC-7 (3), EPI-5 (2), PRV-1 (3) and PRV-3 (2) are scored above their red-line levels. Static review of commit cd6ae2f (shallow clone, one squashed commit); nothing was built or run.

- Question: Is PandaCode safe to run with its defaults on a machine with real repositories and cloud credentials? No. New tasks start in Full access, which disables harness approvals and app-tool approvals except deploy CLIs (storage.rs:23, mcp_host.rs:491). Use Standard or Ask mode, or a VM, for untrusted work.
- Question: Do automated tests gate what users depend on? Partly. Rust core and Node tests gate PRs on Linux; the 619-test UI suite and macOS are outside CI, and 0.3.8 shipped with 8 failing browser tests.
- Question: What is worth extracting or combining with other reviewed repositories? The hardened loopback MCP host, the harness adapters (overlapping t3code and orca), and a pluggable System-One decision endpoint that my-jev or laya could serve.
- Not examined: Runtime behaviour: nothing was built or run; every level comes from reading code, docs and CI files; Most of the roughly 74k Rust lines: sampled providers.rs, providers/mcp_host.rs, agent_tools.rs, storage.rs, workspace.rs, the lib.rs exit path, vm/, cloud/deploy.rs, bots/guard.rs and the channel loop; Frontend injection review beyond spot checks of innerHTML templates in src/github-hub.ts and src/github.ts; The website (website/) beyond the privacy and license pages; Published security advisories, release assets and signatures (no web access); Git history beyond the single squashed commit; The Cloudflare worker (src-tauri/src/cloud/cloudflare_worker) and the Jev runner beyond its telemetry settings
