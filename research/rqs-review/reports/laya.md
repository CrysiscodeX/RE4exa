## Scope

Flags: `distributed`, `heavy_compute`, `network_service`, `parses_untrusted`, `uses_llm`. Not set: `executes_code`, `has_ui`, `uses_crypto`.

Profile ml-system: three checkpoints plus their inference runtimes, ports and evaluation harness. uses_llm=true because laya ships an MCP server and agent-framework integrations executed by agents (it calls no LLM); executes_code=false because the shipped package is CI-gated against subprocess/eval and only dev scripts spawn processes; has_ui=false because the web playground is an example outside the published package; network_service (laya-serve), parses_untrusted (HTTP bodies, Hub model files), heavy_compute (GPU training and inference) and distributed (PyPI, npm, Maven) are true; uses_crypto=false because cryptography is limited to SHA-256 integrity digests and constant-time token comparison, with no signing, encryption or key exchange for SEC-9 to assess. Static review at ffc1420 (shallow clone); weights on Hugging Face were not reachable, so behaviour claims were checked against committed result files, not reruns.

- Question: Are laya's accuracy and calibration claims backed by reproducible evaluations? Mostly: harnesses, seeds, n and dates are committed and a CI test checks table cells against result files, and the 0.466 -> 0.081 ECE refit is out of sample. Exceptions: the fine-tuned 0.766 headline and the 103-332 q/s range have no committed result, and the 'ECE 3x better than Jev' row compares different studies.
- Question: Do shipped probabilities support abstention without refitting? No. Both checkpoints ship over-confident and laya-multilingual has no fitted temperatures; abstention is opt-in. The tooling to fit temperatures and target-error thresholds is present and tested.
- Question: Are code, weights and data licences clear? Code is Apache-2.0 with SPDX identifiers. The weights' Apache-2.0 licence is asserted only in a README table, and the base-encoder and training-data licences (training mix includes AG News and BoolQ) are not documented in the repository; Hugging Face model cards were not reachable.
- Not examined: Model weights, Hugging Face model cards and dataset cards (huggingface.co not reachable); no benchmark or evaluation was rerun.; Git history (shallow clone, 1 commit): contributor count, release cadence, and whether the PyPI token mentioned in security.yml was revoked.; Internals of laya-dotnet, laya-java, laya-go and laya-rust beyond parity tests and CI wiring; notebooks/*.ipynb.; Runtime behaviour of laya-serve and the MCP server (not run); the MCP catalog size is a static lower bound (3 of 10 descriptions not resolvable without import).; Accessibility of the examples/server.py web playground; Docker image contents.; Branch protection and required-review settings (not visible in the repository).
